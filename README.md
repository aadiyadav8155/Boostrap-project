# Trendz Watch ⌚

A premium e-commerce landing page for a luxury watch brand, built with React, Vite, and Bootstrap.

## Features
- Fully responsive modern user interface
- Custom premium color theme
- Hero section with clear Call to Action (CTA)
- Dedicated sections for Brand Story and Product Features
- Secure shopping and responsive grid layout

## Tech Stack
- **Frontend Framework:** React (initialized with Vite)
- **Styling:** Bootstrap & Inline Custom CSS
- **Assets:** Unsplash Images

## Installation & Setup

1. Clone the repository:
   git clone [https://github.com/aadiyadav8155/Boostrap-project.git](https://github.com/aadiyadav8155/Boostrap-project.git)


2. Navigate to the project directory:
```bash
cd Boostrap-project

```


3. Install the required dependencies:
```bash
npm install

```


4. Start the local development server:
```bash
npm run dev

```
